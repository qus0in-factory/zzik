# 0.7 off-peak 스케줄 조사 (2026-11-15)

OpenCode Go, Ollama Cloud, DeepSeek 공식 API의 시간대 할인과, 수집된 OpenCode·Ollama 응답에 할인 신호 필드가 있는지를 기록한다. 값·토큰·식별자·잔액 숫자는 적지 않는다. 공식 문서에 없는 항목은 미확인이다. 배지가 채택한 계약은 [ADR 0.7](../adr/0.7-offpeak-badge.md).

확인일: 2026-11-15. 원본 메모는 세션의 `/tmp/offpeak-opencode.md`, `/tmp/offpeak-ollama.md`, `/tmp/offpeak-deepseek.md`, `/tmp/offpeak-shape.md`.

## 채택 구간 (UTC, 시작 포함·끝 미포함)

| 제공자 | 평일 off-peak | 평일 peak | 토·일 |
|---|---|---|---|
| OpenCode Go | `[00:00, 01:00)`, `[04:00, 06:00)`, `[10:00, 24:00)` | `[01:00, 04:00)`, `[06:00, 10:00)` | 종일 off-peak |
| Ollama Cloud | `[00:00, 12:00)`, `[18:00, 24:00)` | `[12:00, 18:00)` | 종일 off-peak |

요일은 UTC. 중국 공휴일은 두 제공자 문서에 적용 근거가 없어 반영하지 않는다. 시각은 UTC 고정이고 서머타임으로 경계를 옮기지 않는다.

혜택은 둘 다 DeepSeek 계열 토큰 단가가 피크의 절반이다. 배지 데이터는 `effect: { target: 'DeepSeek', discountPercent: 50 }`. 동시성·요청 속도가 off-peak에 풀린다는 문장은 없다.

## OpenCode Go

- **근거**: https://opencode.ai/docs/console/go/#usage-limits (확인 2026-11-15, 조사 시각 UTC 10:41).
- **대상**: DeepSeek V4.1 Flash / V4 Pro. Go·Go Plus·Go Teams 토큰 단가는 같다.
- **구간**: 위 표. off-peak는 문서의 Peak 여집합으로 적었고, 경계는 시작 포함·끝 미포함으로 읽었다.
- **단가 (USD / 100만 토큰)**: Flash off-peak 입력 0.15 / 출력 0.60 / 캐시 읽기 0.003, peak 0.30 / 1.20 / 0.006. Pro off-peak 0.66 / 1.98 / 0.022, peak 1.32 / 3.96 / 0.044.
- **한도**: 5시간·주간·월간은 월 한도의 20%·50%·100%. 시간대별 한도 증액은 없다. 같은 달러 한도면 실효 토큰이 두 배라는 계산은 단가에서 나온 해석이다. 요청 속도·동시성 완화 배수는 미확인.
- **주말**: 문서가 토·일 종일 off-peak라고 적는다.
- **미확인**: OpenCode Go에 DeepSeek 공식 가격의 중국 공휴일 제외가 그대로 적용되는지. 공휴일 판정 시간대·대체근무일. 계절별 UTC 변경이나 DST 예외 공지.
- **Zen**: https://opencode.ai/docs/zen/ 은 https://opencode.ai/docs/console/models/ 로 옮겼다. 현재 표는 Flash $0.30/$1.20/$0.006, Pro $1.74/$3.48/$0.145만 있고 Peak/Off-peak가 없다. Zen의 시간대·할인율·한도 배수는 미확인. V4.1 Flash Free는 기간 한정 무료이지 시간대 할인이 아니다. 대시보드 OpenCode 카드는 Go 사용량이다.

## Ollama Cloud

- **근거**: https://ollama.com/pricing (확인 2026-11-15). 보조로 https://docs.ollama.com/cloud 에 공휴일 조항이 없다.
- **문장**: "Off-peak pricing apply outside 12:00 and 18:00 UTC on weekdays and all day on weekends."
- **구간**: 평일 peak는 12:00–18:00 UTC, off-peak는 그 밖(18:00부터 다음 날 12:00, 주말 종일). 끝점 포함 여부는 페이지가 적지 않는다. 제품은 OpenCode와 같이 `[12:00, 18:00)` peak로 둔다.
- **단가 (USD / 100만 토큰)**: `deepseek-v4.1-flash` peak 입력 0.30 / 캐시 입력 0.006 / 출력 1.20, off-peak 0.15 / 0.003 / 0.60. `deepseek-v4-pro` peak 1.32 / 0.044 / 3.96, off-peak 0.66 / 0.022 / 1.98. Pro·Max·Team 포함 크레딧과 종량 크레딧에 이 단가가 적용된다.
- **미확인**: 공휴일·지역·그 밖의 예외. off-peak 동시성·레이트 리밋 완화. 페이지의 동시 요청 한도는 플랜 고정값(종량·Pro 3, Max·Team 10)만 있다.

## DeepSeek 공식 API (참고, 배지 대상 아님)

- **근거**: https://api-docs.deepseek.com/quick_start/pricing 각주 (2), 중문 https://api-docs.deepseek.com/zh-cn/quick_start/pricing (확인 2026-11-15). 변경 로그 https://api-docs.deepseek.com/updates.
- **유효**: 2026-11-15 가격 페이지에 피크/오프피크가 있다. 오프피크는 피크의 절반. 2026-10-17 로그는 가격 유지, 2026-11-13 항목은 이 시간대를 철회하지 않는다.
- **피크**: 월–금 01:00–04:00과 06:00–10:00 UTC, 중국 법정공휴일 제외. 그 밖·주말·공휴일 전일은 off-peak. 중문은 베이징 월–금 9:00–12:00, 14:00–18:00(공휴일 제외)이며 UTC+8로 같은 창이다.
- **모델**: `deepseek-flash`(DeepSeek-V4.1-Flash-1017), `deepseek-v4-pro`(DeepSeek-V4-Pro-0813). 캐시 히트·미스 입력과 출력 모두 두 단가. USD / 100만 토큰: Flash off-peak 0.003 / 0.15 / 0.6, peak 0.006 / 0.3 / 1.2. Pro off-peak 0.022 / 0.66 / 1.98, peak 0.044 / 1.32 / 3.96. 중문 페이지는 위안 단가고 환율 환산은 없다.
- **시간대 할인이 아닌 것**: 검색·웹 fetch·파일 파싱/OCR·TTS·ASR. TTS·ASR의 기간 한정 50%는 별도다.
- **이력**: 2025-02-26 매일 16:30–00:30 UTC(V3 50%, R1 75%, https://x.com/deepseek_ai/status/1894710448676884671)는 2025-09-05 16:00 UTC에 끝났다(https://api-docs.deepseek.com/news/news250821). 현재 창은 2026-08-16 16:00 UTC에 다시 열렸다(https://api-docs.deepseek.com/news/news260813). 2026-09-10 04:00 UTC에 단가만 내렸고 50% 구조는 유지(https://api-docs.deepseek.com/news/news260910).
- **미확인**: 경계 시각의 포함 관계(문장은 `-`만 씀). 공휴일 날짜 목록. 피크 창 문장이 나중에 주말·공휴일 전일 제외로 바뀌었는지(변경 로그에 별도 항목 없음). 2025-02-26 창이 당시 가격 페이지 본문에도 있었는지.

## 실응답 형상 (2026-11-15)

`scripts/usage-live-shape.sh`가 PostgreSQL `usage_snapshot`의 envelope를 읽고 `rawText`의 키는 유지한 채 문자열만 가렸다. 숫자 원문은 이 문서에 옮기지 않는다. `rawOmitted`는 null, HTTP 200, status ok.

| 제공자 | 키 |
|---|---|
| opencode | `usage.{rolling,weekly,monthly}.{status,percent,resetsAt}` |
| ollama | `included.{balance_usd,allowance_usd,period.{from,until}}`, `purchased.balance_usd` |

off-peak·peak·discount·multiplier 키는 없었다. OpenCode `resetsAt`은 한도 창 경계다. Ollama `period`는 정산 구간이다. 픽스처 `tests/fixtures/{opencode,ollama}-usage.*.json`과 `collector/`에도 그 키는 없다(`unknown-keys` 픽스처의 `unknown_field`·`usage.daily`는 예외 케이스용이다).

그래서 배지는 응답 필드를 읽지 않는다. 상류에 해당 필드가 생기면 응답을 정본으로 다시 본다.
