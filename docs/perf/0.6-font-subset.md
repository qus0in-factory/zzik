# 0.6 폰트 dynamic subset: 첫 로드 전송량 측정

Refs #43. ADR 0.6(grok·ollama·opencode 수집)은 화면 성능과 무관해 별도 문서로 둔다.

## 변경

`src/ui/index.css`의 Pretendard를 단일 `PretendardVariable.woff2`(2.06MB)에서 `pretendardvariable-dynamic-subset.css`(unicode-range로 92조각)로 바꿨다. 화면에 쓰인 글자가 속한 조각만 내려받는다. 글꼴 스택은 `'Inter', 'Pretendard Variable', system-ui`.

## 측정 방법 (재현 가능)

스크립트: `scripts/measure-transfer.mjs`(+ 공용 헬퍼 `scripts/lib/cdp.mjs`).

- 헤드리스 Chrome을 띄워 DevTools 프로토콜의 `Network.loadingFinished.encodedDataLength`(전송 바이트, 압축 후)를 합산한다.
- `Network.setCacheDisabled`로 캐시를 끄고, 페이지 이동 후 6초 기다린다(폰트·API 요청 포함).
- 대상은 `vite build` 결과를 `vite preview`로 서빙한 URL이다.

```sh
# 변경 전: 0.6/gerbil 기준 커밋(6757940)에서
pnpm vite build --outDir /tmp/polish/dist-before && pnpm vite preview --outDir /tmp/polish/dist-before --port 4198 &
# 변경 후: 0.6/ui-polish에서
pnpm vite build --outDir /tmp/polish/dist-after && pnpm vite preview --outDir /tmp/polish/dist-after --port 4199 &
node scripts/measure-transfer.mjs http://localhost:4198/
node scripts/measure-transfer.mjs http://localhost:4199/
```

## 결과 (2026-11-14, macOS, headless Chrome, 로컬 preview)

| 항목 | 변경 전 | 변경 후 |
|---|---|---|
| 첫 로드 전송량 합계 | 2,275,224 B (2,221.9 KB) | 418,338 B (408.5 KB) |
| 요청 수 | 13 | 19 |
| Pretendard | 단일 woff2 2,058,012 B | 조각 6개, 각 약 21~38 KB |
| CSS 파일 크기(vite) | 31.21 kB (gzip 6.53) | 80.51 kB (gzip 21.94) |
| JS 파일 크기(vite) | 373.74 kB (gzip 117.99) | 375.25 kB (gzip 118.34) |

전송량은 약 82% 줄었다. CSS는 `@font-face` 92개 때문에 커졌지만 gzip 기준 +15 KB로, 폰트 절감분(약 1.9MB)에 비해 작다. 요청 수는 6개 늘지만 조각이 병렬로 내려간다.

## 한계

- 로컬 preview 측정이라 네트워크 지연·HTTP 캐시 헤더는 반영하지 않는다(캐시는 일부러 껐다).
- 조각 수는 화면에 쓰인 한글에 따라 달라진다. 이 화면(제공자·카드 문구) 기준 6조각이다.
