## 0. 계약 (테스트가 공유하는 고정값)

### 0.1 픽스처

| 파일 | 의도 | 창 | 항목(metric) | 기대 report.status |
|---|---|---|---|---|
| `claude-usage.normal.json` | 평시 | `five_hour`, `seven_day` | `seven_day_opus`(null), `seven_day_sonnet`, `extra_usage` | `normal` |
| `claude-usage.warn.json` | 80% 이상 경고 | 〃 | `seven_day_opus`(null), `seven_day_sonnet`, `seven_day_oauth_apps`, `extra_usage` | `warn` |
| `claude-usage.limited.json` | 100% 이상 + 경계 | 〃 | `seven_day_opus`(null), `seven_day_sonnet`(104), `seven_day_cowork`(100, 리셋 지남), `extra_usage`(100, resets_at 없음) | `limit` |
| `claude-usage.unknown-keys.json` | 미지 키·null·패턴 파생 | 〃 | `seven_day_opus`(null), `seven_day_sonnet`, `seven_day_fable`, `seven_day_haiku`(resets_at null), `seven_day_cowork`(null), `thirty_day`, `extra_usage` | `normal` |

실제 응답 형태를 지킨다: 최상위 키의 값은 **`{ utilization: number, resets_at?: string }` 또는 `null`**. 래퍼(`data`, `as_of` 등)를 두지 않는다. `extra_usage`는 실제 응답처럼 `resets_at`이 없다.

### 0.2 고정 시각

```
NOW = 2026-11-11T12:00:00.000Z
```

`resets_at`은 모두 ISO-8601(Z) 문자열이며 위 `NOW` 기준으로 계산한다. 테스트는 `now`를 **주입**한다(전역 `Date.now()` 의존 금지).

### 0.3 결정 사항 (테스트가 이 결정을 고정한다)

| ID | 결정 | 이유 |
|---|---|---|
| C1 | `five_hour` → **창(primary)**, `seven_day` → **창(secondary)**. 창은 `windows`에만 들어가고 `metrics`에 중복 수록하지 않는다. | biseo는 둘을 metric에도 넣지만 UI 카드가 중복되므로 0.2.1은 분리. |
| C2 | 나머지 최상위 키 중 값이 **객체이고 `utilization`(number) 또는 `resets_at`(string)을 하나라도 가진 것**을 metric으로 수집한다. | biseo `claude-oauth-items.ts` 규칙. |
| C3 | 값이 `null`인 키도 **metric으로 유지**하고 `utilization: null`, `status: 'unknown'`으로 표현한다. 카드에는 "정보 없음"으로 표시. | "미제공"과 "0%"를 구분. 삭제하면 사용자가 Opus 상태를 알 수 없다. |
| C4 | 상태 레벨은 기존 `getUsageStatus` 임계값을 그대로 쓴다: `>=100 → limit`, `>=80 → warn`, 그 외 `normal`. `null`/비정상 → `unknown`. | `src/domain/usage-status.ts` 재사용, 새 임계값 도입 금지. |
| C5 | `resets_at`이 `NOW` 이전이면 `expired: true`. **`status`는 utilization으로만 결정**하고(그래서 100%면 limit 배지), `report.status` 집계에서 `expired` 항목은 제외한다. | 리셋이 지난 100%를 "지금 막혔다"로 오표시하지 않기 위해. biseo의 `state` 판정과 동치. |
| C6 | `resets_at`이 없거나 `null`인 100%는 만료 판정 불가이므로 **만료 아님(집계 포함)** 으로 본다. | 보수적(안전한 쪽) 판정. |
| C7 | `report.status` 집계 순서: 유효(비만료) `limit` ≥1 → `limit`; 아니면 `warn` ≥1 → `warn`; 아니면 값 있는 항목이 전부 정상 → `normal`; 전부 `unknown` → `unknown`. | 단일 등급으로 헤더 배지 표시. |
| C8 | 정렬: 창은 `five_hour`, `seven_day` 고정 순서. metric은 ① 알려진 id 고정 순서(`seven_day_opus`, `seven_day_sonnet`, `seven_day_oauth_apps`, `seven_day_cowork`, `extra_usage`) ② 그 뒤 미지 id **사전순**. | 렌더 결과를 결정적으로 만들어 스냅샷/쿼리 테스트 가능. |
| C9 | 라벨: 고정 표 → `five_hour`=`5시간 한도`, `seven_day`=`주간 한도`, `seven_day_opus`=`Opus 주간`, `seven_day_sonnet`=`Sonnet 주간`, `seven_day_oauth_apps`=`OAuth 앱 주간`, `seven_day_cowork`=`Cowork 주간`, `extra_usage`=`추가 사용량`. `seven_day_<slug>` → `주간 · <Slug>`, `five_hour_<slug>` → `5시간 · <Slug>` (Slug: `_`→공백, 각 단어 첫 글자 대문자). 그 외 → **id 원문**. | 새 모델이 추가돼도 카드가 사라지지 않는다. |
| C10 | 위 C9의 2·3번(패턴 파생/원문)은 `unknown: true`로 표시하고 UI에 "미확인" 배지를 붙인다. | 스키마 변경을 사람이 인지하도록. |
| C11 | `raw`(원본 JSON 객체)를 리포트에 **그대로 보존**한다. | raw JSON 토글이 파싱 결과가 아니라 원본을 보여줘야 함. |
| C12 | 파서는 **던지지 않는다**. 형식 오류는 `issues[]`(`{ code, key? }`)로 모으고 부분 결과를 반환한다. | 목 UI가 깨지지 않고, 오류 UI 시나리오를 테스트할 수 있다. |
| C13 | `utilization`이 음수·비유한·문자열이면 `null` + `issues: [{ code: 'invalid_utilization', key }]`. `100` 초과(예: 104)는 **정상 overage**로 허용. | 기존 `usage-status.ts`의 검증 규칙과 일치. |

### 0.4 타입 초안 (구현 대상, 레포 파일 아님)

```ts
// src/domain/usage-raw.ts
export type RawUsageEntry = { utilization?: number | null; resets_at?: string | null } | null
export type RawUsage = Record<string, RawUsageEntry>

// src/domain/usage-types.ts
export type UsageLevel = 'normal' | 'warn' | 'limit' | 'unknown'

export interface UsageWindow {
  id: 'five_hour' | 'seven_day'
  label: string
  usedPercent: number | null
  resetsAt: string | null
  expired: boolean
  status: UsageLevel
}

export interface UsageMetric {
  id: string
  label: string
  unknown: boolean
  usedPercent: number | null
  resetsAt: string | null
  expired: boolean
  status: UsageLevel
}

export interface UsageReport {
  status: UsageLevel
  windows: UsageWindow[]
  metrics: UsageMetric[]
  issues: Array<{ code: string; key?: string }>
  raw: RawUsage
}
```

### U7. raw JSON 토글

- **When** "원본 JSON" 버튼 클릭

- **And** 미지 키(`unknown-keys`)도 원문 그대로 포함된다(파싱 결과 아님)
- **When** 다시 클릭
- **Then** 접히고 DOM에서 `<pre>`가 사라진다
- 테스트: `tests/ui/UsageRawJson.test.tsx`

### U8. 320px 1열

- 테스트: `tests/ui/UsageDashboard.test.tsx`

### U9. 접근성 — 제목/랜드마크/숫자
